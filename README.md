# Workout Plan

Sai's daily workout + podcast coach, hosted on GitHub Pages:
**https://kriskrss.github.io/workout-coach/**

- 20 min strength (5 days/week) + 40 min walk/cardio; rest days are 60 min cardio.
- Audio coach guides each block; each day deep-dives one system-design concept using the
  "Riya and Dev" Educative podcast episodes, stored in `episodes/` next to the app so
  playback works in-page (player + timer on one screen).
- Add to Home Screen from the address above and it installs as its own app
  ("Workout Plan") — its own manifest and icons live in this repo.

Progress is stored in the browser on the phone (localStorage). Week 1 queues are baked in;
later weeks update by editing `index.html` here and pushing.
